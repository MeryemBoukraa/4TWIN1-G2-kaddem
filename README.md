# Projet DevOps - Microservice Ressource Pédagogique

Ce projet fait partie d'une plateforme universitaire basée sur une architecture **microservices**, avec une orientation DevOps pour l'automatisation des processus CI/CD, la containerisation, le monitoring et le déploiement cloud.

## Microservice Ressource Pédagogique

Ce microservice permet la gestion des ressources pédagogiques (fichiers PDF, cours, résumés, etc.) pour les étudiants et enseignants. Il est développé avec **Spring Boot**, expose des API REST, et utilise une base de données **MySQL**.

---

## Objectifs du Projet

- Implémenter le microservice `ressource-pedagogique`
- Automatiser le build et le déploiement avec CI/CD
- Utiliser Docker pour la containerisation
- Intégrer le service via un **API Gateway** (Spring Cloud Gateway)
- Monitorer avec Prometheus et Grafana
- Déployer sur docker hub

---

##  Stack Technique

- **Backend** : Spring Boot, Spring Data JPA
- **Base de données** : MySQL
- **API Gateway** : Spring Cloud Gateway
- **Découverte de services** : Eureka
- **CI/CD** : GitHub Actions / Jenkins
- **Containerisation** : Docker
- **Monitoring** : Prometheus, Grafana
- **Tests** : JUnit, Mockito
